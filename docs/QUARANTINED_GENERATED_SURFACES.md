# Quarantined generated surfaces

The legacy mutable catalog, royalty, contract, license, platform, artist, payment, AI, optimizer, acquisition, clearance, plagiarism, earnings, and every `gap-*` route remain in the repository only for provenance review. They are not mounted by `server/index.js` and are not supported product capability.

In particular, the old royalty/payment routes permit arbitrary creation, update, and deletion without tenant ownership, effective contract versions, independent approvals, locked periods, immutable evidence, posting idempotency, or reconciliation. Direct model output and generated gap surfaces cannot calculate, approve, post, or reverse money. Re-enabling any quarantined route requires a threat model, tenant-safe durable schema, typed integration contract, explicit failure behavior, authorization tests, migration review, and owner approval.
